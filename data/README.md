# External numerical data

Full meshes, snapshot banks, complete trajectories, trained weights, and large result folders are not stored in Git. Configure a local data root from `configs/data_locations.template.yml` or set `PARAMPLATE_DATA_ROOT`. The active archive schemas are documented in `../docs/data-and-manifests.md` and can be checked with `paramplate-validate-archive`.

The `sample/` directory is reserved for small, explicitly generated smoke data. It contains no thesis campaign results.
